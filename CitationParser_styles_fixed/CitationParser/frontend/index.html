📘 About This Project

This tool solves a major problem in Indian academic research: Indian regional journals are not indexed in major databases like Scopus or CrossRef, making it hard to generate proper citations automatically.

🔄 Parsing Pipeline

Step 1: PDF Text Extraction (pdfplumber → PyMuPDF fallback)
Step 2: DOI Regex Detection (15+ patterns for Indian formats)
Step 3: CrossRef API Lookup (Free, 95%+ accuracy if DOI found)
Step 4: OpenAI GPT-4o-mini (for non-standard formats)
Step 5: Regex Fallback (year, volume, ISSN, keywords)
Step 6: BibTeX Generation (ready for LaTeX .bib files)

🔌 API Endpoints

POST /api/v1/parse/pdf — Upload PDF file
POST /api/v1/parse/doi — Lookup by DOI
POST /api/v1/parse/text — Parse citation text
POST /api/v1/bibtex/from-doi — Raw BibTeX
GET /api/v1/health — Server health check
